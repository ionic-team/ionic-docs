### アクセシビリティ {/* #a11y */}

[アクセシビリティ](https://developer.mozilla.org/en-US/docs/Web/Accessibility)（a11y）とは、能力に制限のある人であっても、できるだけ多くの人がコンテンツを利用できるようにする実践のことです。これには障害を持つ人、モバイルデバイスを使用する人、ネットワーク接続が遅い人が含まれます。コンテンツは、可能な限り技術が許す範囲でアクセス可能に開発されるべきです。

### Android SDK {/* #android-sdk */}

[Android SDK](http://developer.android.com/sdk/index.html)は、GoogleのAndroidプラットフォーム向けに開発する開発者のために構築されたソフトウェア開発キットです。これには、Androidアプリケーションの構築、テスト、デバッグのためのツールが含まれます。

### Android Studio {/* #android-studio */}

[Android Studio](https://developer.android.com/studio/)は、ネイティブAndroidアプリ開発の公式統合開発環境（IDE）です。

### Autoprefixer {/* #autoprefixer */}

[Autoprefixer](https://github.com/postcss/autoprefixer)は、手書きのSass/CSSコードにベンダー固有のプレフィックスを追加するツールです。これにより、あなたが書いた標準化されたCSSルールがすべての対応ブラウザで適用されることが保証されます。たとえば、さまざまなブラウザで使用されるすべてのフレックスボックスの構文を覚える代わりに、Autoprefixerを使えば単に<code>display: flex;</code>と書くだけで、自動的に正しいCSSが挿入されます。

### バンドリング {/* #bundling */}

バンドリングとは、アプリの依存関係（あなたが書いたコードやインストールしたnpmモジュール）を一つのファイルにコンパイル/トランスパイルするプロセスです。

### Capacitor {/* #capacitor */}

[Capacitor](https://capacitorjs.com/)は、WebベースのアプリをiOS、Android、Electron、Web上でネイティブに実行できるオープンソースのクロスプラットフォームアプリランタイムです。これらのアプリを「ネイティブプログレッシブWebアプリ」と呼ぶと便利で、従来のハイブリッドアプリの考え方を超えた次の進化を表しています。CapacitorはIonic社によって作成され、現在も開発およびサポートが行われています。

{/* cspell:disable */}

### CLI {/* #cli */}

CLI、または**C**ommand-**L**ine **I**nterfaceは、
プログラムと対話するためのテキストベースのインターフェースです。Macユーザーに一般的なコマンドラインアプリはTerminalアプリであり、WindowsユーザーはしばしばCommand Promptを使用します。Ionicコミュニティでは、この用語は[IonicのCLI](https://ionicframework.com/docs/cli)を指すことがよくあります。IonicのCLIは、アプリの本番ビルドの作成、開発サーバーの実行、[Ionic商用サービス](https://ionic.io/appflow)へのアクセスなど、さまざまなことに使用できます。

{/* cspell:enable */}

### CommonJS {/* #commonjs */}

[CommonJS](https://webpack.github.io/docs/commonjs.html)は、JavaScriptのAPIの標準フォーマットを定義するグループです。JavaScriptモジュールおよびパッケージの標準を定義しています。

### Cordova {/* #cordova */}

[Apache Cordova](https://cordova.apache.org)は、標準のHTML/CSS/JSを本格的なネイティブアプリに変換するオープンソースのモバイルアプリケーション開発フレームワークです。カメラや加速度計などのネイティブデバイス機能にアクセスするためのJavaScript APIを提供します。Cordovaには、iOS、Android、およびWindows Phone用にウェブアプリをパッケージ化するための必要なビルドツールが含まれています。

### CORS {/* #cors */}

[CORS](https://developer.mozilla.org/en-US/docs/Web/HTTP/CORS)
（クロスオリジンリソース共有）は、サーバーがクライアントのウェブ資産へのアクセスを制御するための仕組みです。詳細は[CORSよくある質問](../troubleshooting/cors)をご覧ください。

### CSS変数 {/* #css-variables */}

あなたはSassの変数に馴染みがあるかもしれません。
[CSS変数](https://developers.google.com/web/updates/2016/02/css-variables-why-should-you-care)は同じ機能を提供しますが、ブラウザに組み込まれています。CSS変数はすべての最新ブラウザで利用可能です。

### デコレーター {/* #decorators */}

デコレーターは、関数を返す式です。既存の関数を取り、その挙動を拡張することができます。TypeScriptでは、*クラス*や*パラメーター*もデコレーションできます。

**クラス**
をデコレーションすると、そのコンストラクターの挙動をラップして拡張します。言い換えれば、デコレーターはコンストラクターが呼ばれた際に機能を追加し、元のコンストラクターを返します。
**パラメーター**
をデコレーションすると、そのパラメーターに渡される引数をラップします。デコレーターは、メソッドに引数が渡された際に機能を追加し、元の引数を返します。

### ES5 {/* #es5 */}

ES5はEcmaScriptの第5版を指します。簡単に言えば、ES5は今日の開発者が最もよく知っているJavaScriptのバージョンです。

### ES2015/ES6 {/* #es2015-es6 */}

このバージョンのJavaScriptでは、クラス、モジュール、イテレーター、プロミスなど、幅広い新機能が導入されました。エバーグリーンブラウザ（Chrome、Safari、Firefox、Edge）はES6を完全にサポートしていますが、古いブラウザでES6の機能を使用するには、[Babel](#babel)や[TypeScript](#typescript)などのツールでES6のコードをES5に[トランスパイル](#transpiler)する必要があります。

### ES2016/ES7 {/* #es2016-es7 */}

このバージョンの JavaScript では、<code>Array.includes</code> や指数演算子など、多数の新機能が言語に追加されました。このバージョンの JavaScript は、すべてのエバーグリーンブラウザ（Chrome、Safari、Firefox、Edge）で完全にサポートされています。

### ES2017/ES8 {/* #es2017-es8 */}

このバージョンのJavaScriptは最新の標準です。現在、新しい公式標準になる前の最終段階にあります。この仕様には、Async/Await（すでにすべての最新ブラウザで使用可能）と共有メモリ/アトミクスが含まれています。

### Genymotion {/* #genymotion */}

Genymotionはサードパーティ製のAndroidエミュレーターです。非常に高速で、Android上でアプリを素早くテストするのに役立ちます。
Genymotionに関する詳細情報は、[リソースセクション](../developing/tips#using-genymotion-android)をご覧ください。

### Git {/* #git */}

[Git](https://git-scm.com/)はコードを管理するための分散型バージョン管理システムです。
これにより、開発チームは同じプロジェクトにコードを追加しても、コードの競合を引き起こすことなく作業できます。

### Gulp {/* #gulp */}

[Gulp](http://gulpjs.com/)は、アプリをビルドするためのタスクを実行するツールです。
一般的なビルドタスクには、[ES6](#es2015-es6)を[ES5](#es5)に変換すること、[Sass](#sass)をCSSに変換すること、コードの最小化、ファイルの結合などがあります。

### ES Modules {/* #es-modules */}

[ES Modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/import)は、JavaScriptにネイティブでモジュールの概念をもたらします。
モジュールを使用すると、クラスや変数はもはやグローバルスコープではなく、プロジェクト内で使用するには明示的にインポートする必要があります。
これにより、コードの出どころを理解しやすくなり、機能のモジュール化および分離が向上します。

### Ionicons {/* #ionicons */}

[Ionicons](https://ionic.io/ionicons/) は、Ionic によって作成および使用されるオープンソースのアイコンセットです。これには、1:1 の iOS アイコンと Material Design アイコン、さらに一般的に使用されるソーシャル/アプリケーションアイコンが含まれます。Ionicons は Ionic の配布版にデフォルトで含まれていますが、任意のプロジェクトでも使用できます。

### Karma {/* #karma */}

[Karma](https://karma-runner.github.io/latest/index.html) は、アプリのテストを実際のブラウザ内で実行するテストランナーです。任意のテストフレームワークで書かれたテストケースを実際のブラウザで実行します。Karma はもともと Angular 1 用に書かれました。

### モジュール {/* #module */}

JavaScript のモジュールは、小さく独立して再利用可能なコードの断片で、互いに隔離されており、グローバルスコープからも独立しています。

### モノレポ {/* #monorepo */}

**モノレポ** は、複数のプロジェクトを含む単一の git
リポジトリです。利点には、組織の簡素化、ツールや依存関係の共有、チームメンバーとの協力の向上などがあります。

### ライブリロード {/* #livereload */}

**ライブリロード**（または **live-reload**）は、アプリの変更を検出すると自動的にブラウザや
[Webビュー](../core-concepts/webview)をリロードするツールです。場合によっては、ウィンドウ全体をリロードせずに
アプリの一部を置き換えることもできます。詳細は[ライブリロードのドキュメント](../cli/livereload)を参照してください。

### Node {/* #node */}

[Node](https://nodejs.org/) は、サーバーサイドで JavaScript を書くことを可能にするランタイム環境です。ウェブサービスで使用されることに加えて、node は開発者ツールの構築にもよく使用されます。例えば [Ionic CLI](#cli) のようなものです。

### npm {/* #npm */}

[npm](https://www.npmjs.com/)は[node](#node)のパッケージマネージャーです。
これにより、開発者はノードモジュールをインストール、共有、パッケージ化することができます。Ionicはnpmでインストールでき、その依存関係のいくつかも一緒にインストール可能です。

### オブザーバブル {/* #observable */}

オブザーバブルはイベント（または通知）を発行するオブジェクトです。オブザーバーはこれらのイベントを受け取るオブジェクトで、イベントを受信したときに何かを行います。一緒に使用すると、非同期プログラミングに利用できるパターンが作られます。

### パッケージID {/* #package-id */}

Appleでは**バンドルID**、Androidでは**アプリケーションID**と呼ばれる**パッケージID**は、App Store/Play Storeに公開されるアプリの識別に使用されます。これは[リバースDNS表記](https://en.wikipedia.org/wiki/Reverse_domain_name_notation)でフォーマットされた文字列です。

### ポリフィル {/* #polyfill */}

[ポリフィル](https://remysharp.com/2010/10/08/what-is-a-polyfill)は、ブラウザに機能を追加し、ブラウザ間の違いを統一するコードのことです。これは[シム](#shim)に似ていますが、シムは独自のAPIを持つのに対し、ポリフィルはブラウザが提供する期待されるAPIを使用できるようにします。

### プロトラクター {/* #protractor */}

[プロトラクター](https://angular.github.io/protractor/#/)はAngularチームによって書かれたテストフレームワークです。プロトラクターはKarmaなどのテストランナーと組み合わせて、エンドツーエンドテストに使用できます。テストランナーを使うことで、コードの品質を迅速かつプログラム的に検証できます。

### Sass {/* #sass */}

SassはCSSにコンパイルされ、Ionicで使用されるスタイルシート言語です。SassはCSSのようなものですが、次のような追加機能があります：[変数](http://sass-lang.com/documentation/file.SASS_REFERENCE.html#variables_)、
[ミックスイン](http://sass-lang.com/documentation/file.SASS_REFERENCE.html#mixins)、および
[ループ](http://sass-lang.com/documentation/file.SASS_REFERENCE.html#_10)。

### Scoped Encapsulation（スコープ付きカプセル化） {/* #scoped */}

スコープ付きカプセル化を使用するコンポーネントは、実行時に各スタイルにデータ属性を付加することで自動的にCSSのスコープを設定します。CSSでスコープ付きセレクタを上書きするには[より高い特異性](https://developer.mozilla.org/en-US/docs/Web/CSS/Specificity)のセレクタが必要です。スコープ付きコンポーネントは[CSSカスタムプロパティ](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_variables)を使ってスタイリングすることもできます。

### シャドウDOM {/* #shadow */}

[シャドウDOM](https://developers.google.com/web/fundamentals/web-components/shadowdom)
は、コンポーネントのDOMおよびスタイルのカプセル化のためのネイティブブラウザソリューションです。コンポーネントを周囲の環境から遮蔽します。シャドウDOMコンポーネントの内部要素を外部からスタイルするには、
[CSSカスタムプロパティ](https://developer.mozilla.org/en-US/docs/Web/CSS/Using_CSS_variables)
または [CSSシャドウパーツ](https://developer.mozilla.org/en-US/docs/Web/CSS/::part) を使用する必要があります。

### シム {/* #shim */}

シムは、ブラウザ間のAPIを標準化するコードのことです。シムは、エンドユーザーからブラウザ固有の実装を隠す独自のAPIを持つことができます。

### トランスパイラ {/* #transpiler */}

トランスパイルとは、コードを実行前にある言語から別の言語に変換するプロセスのことです。通常、トランスパイラは高水準言語から別の高水準言語に変換します。Ionic Frameworkで最も一般的な*トランスパイル*の種類は、[ES2015/ES6](#es2015-es6)（[TypeScript](#typescript)）を [ES5](#es5)（従来のJavaScript）に変換することです。

### TypeScript {/* #typescript */}

[TypeScript](http://www.typescriptlang.org) は JavaScript のスーパーセットであり、これは JavaScript に加えて次のような多くの追加機能を提供することを意味します：
[型宣言](http://www.typescriptlang.org/Handbook#basic-types)
および [インターフェース](http://www.typescriptlang.org/Handbook#interfaces)。
Ionic は TypeScript で構築されていますが、Ionic アプリを作成する際に TypeScript を使用するかどうかは完全に任意です。

### ユニットテスト {/* #unit-tests */}

ユニットテストおよびユニットテストは、小さなコードの部分が期待通りに動作するかどうかを確認する方法です。ユニットテスト
フレームワークには Jasmine、Mocha、QUnit、その他多くがあります。

### Webpack {/* #webpack */}

[Webpack](https://webpack.github.io/) は JavaScript モジュールおよびその他のアセットをまとめます。
必要な時にのみ読み込まれる単一または複数の「チャンク」を作成するために使用できます。Webpack は、多数のファイルや依存関係をまとめて 1 つのファイルまたはその他の種類にバンドルするために使用できます。

### ウェブ標準 {/* #web-standards */}

[ワールド・ワイド・ウェブ・コンソーシアム](https://www.w3.org/)（W3C）は、ウェブの標準化団体です。業界のリーダーと一般の人々が一緒に協力し、[ウェブ標準](https://www.w3.org/standards/)を開発します。ウェブ標準とは、ウェブプラットフォームを定義する一連のプロトコル、仕様、および技術のことです。

### Xcode {/* #xcode */}

[Xcode](https://developer.apple.com/xcode/)は、Appleのオペレーティングシステム（macOS、iOS、watchOS、tvOS）向けソフトウェア開発用のAppleの統合開発環境（IDE）であり、他の言語やプラットフォーム向けの拡張も利用可能です。
